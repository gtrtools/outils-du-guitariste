Écrire des suites d’accords

Cliquez dans une mesure pour choisir un accord. Il dure jusqu’au prochain accord, même dans la mesure suivante.

Informations sur la suite

Utilisation

Utilisez le bouton + sous une mesure pour en ajouter une après celle-ci.

Cliquez sur les barres aux extrémités des mesures pour ajouter ou retirer une reprise.

Utilisez ↵ après une mesure pour commencer une nouvelle ligne, puis ↑ sur la mesure suivante pour annuler ce retour.

L’export MusicXML contient la partition et une tablature avec des doigtés calculés automatiquement ; certaines notes non essentielles peuvent être omises. Le capodastre ne transpose pas les accords ; les cases sont comptées depuis le capodastre.

Le lecteur utilise des échantillons de guitare nylon, de guitare acoustique et de piano. Il peut jouer toute la suite, une partie ou une plage de mesures, une fois ou indéfiniment. Les reprises sont respectées pour la suite entière ou une partie, mais ignorées pour une plage de mesures. Modifier la suite arrête la lecture.

Le métronome est facultatif. Le tempo en BPM compte les temps indiqués ci-dessus : en 6/8, 9/8 et 12/8, il compte les noires pointées.
